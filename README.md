# Mini_project
Crime Pattern Analysis, Detection, and Prediction using Machine Learning
This repository contains the source code, documentation, and presentation for my 7th Semester Mini Project focused on applying Machine Learning techniques to analyze, detect, and predict crimes in urban environments.
Project Overview
This project uses real-world crime datasets to uncover spatial and temporal crime patterns, identify crime-prone areas, and predict future crimes based on historical data. By analyzing variables like:

📅 Date of occurrence and report

🏙️ Neighborhood
🕵️‍♀️ Type of offense
📊 Major Crime Indicators (MCI)

We aim to assist law enforcement agencies in strategic planning and help the general public stay informed about the safety of their locality.
Objectives
Identify high-risk neighborhoods requiring more police attention.
Find crime hotspots based on time and location.

Predict:
The next likely crime type.
The location and time it might occur.
Provide a combined analysis of crime data with demographic insights.
